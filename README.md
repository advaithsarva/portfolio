## 🚀 Free Hosting Deployment Guide

This portfolio has **zero build dependencies**. It is written in standard HTML5, CSS3, and modern ESModules, making it 100% free to host on any static hosting provider.

### Option 1: GitHub Pages (Recommended)
1. Initialize git inside this folder:
   ```bash
   git init
   git add .
   git commit -m "feat: initial ZER0 neo-brutalist portfolio"
   ```
2. Create a repository on GitHub named `<your-username>.github.io`.
3. Push to `main`:
   ```bash
   git remote add origin https://github.com/<your-username>/<your-username>.github.io.git
   git branch -M main
   git push -u origin main
   ```
4. Your site will automatically go live at `https://<your-username>.github.io` with free HTTPS!

### Option 2: Netlify Drop (Instant Drag & Drop)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the `portfolio-zer0` folder directly into your browser window.
3. Your site is instantly live on a free `*.netlify.app` domain.

### Option 3: Vercel
1. Run `npx vercel` inside this folder and follow the prompts.
2. Instant free deployment on `*.vercel.app`.

## 🕹️ Interactive Features

1. **Three.js 3D Neural Brain**: Drag to rotate the cortical brain topology rendered with ZER0 color tokens.
2. **Project Carousel**: Interactive slide navigation with index badges `[01]` through `[06]`, tags, and architecture modals.
3. **Interactive Console (`terminal.sh`)**: Type `whoami`, `projects`, `skills`, `pokedex`, `theme`, or `contact`.
4. **Retro 8-bit Porygon Companion (`POKEDEX.EXE`)**: Synthesizes authentic 8-bit square-wave audio chimes via Web Audio API and dispenses witty AI commentary.
5. **Dark / Light Mode**: Seamlessly switches between Warm Paper and Deep Obsidian while maintaining high-contrast brutalist borders.
